# Разработка системы для управления рецептами
Домашнее задание №2 по "Технологии программирования"

## Краткое описание проекта:
Проект представляет собой программу для управления рецептами и формирования списка покупок. Пользователь может создавать рецепты, указывать необходимые ингредиенты, рассчитывать нужное число продуктов в зависимости от количества порций, составлять общий список покупок для использования в разных рецептах, а также работать с диетическими рецептами.


## Использование:
Основной код программы находится в файле recipes.py, тесты в файле test_recipes.py


## Установка: 
Для запуска проекта необходимо клонировать репозиторий и установить зависимости.

```bash
git clone https://github.com/dwqdddh/TP_HW2.git
cd TP_HW2
pip install -r requirements.txt
```
Для запуска тестов:

```bash
py -m pytest
```
